# v2 实际检查记录及验证边界

本文件区分实现检查、独立数值基准、统计稳定性及真实设备验证。全部实际 CFD 在本机 OpenFOAM Foundation 14、离线容器中运行；不是随机生成场或调用远程 CFD。界面检查用 Qt offscreen，未打开实际桌面窗口。

| 已执行检查 | 结果 | 能证明什么 |
|---|---|---|
| 自动化检查 | 42 项通过 | 既有功能及新物理计算、数据读取、几何和 GUI 路径的内部一致性 |
| 原 EPANET 网络 | 质量平衡、Darcy 阻力、能耗和储水检查通过 | 原网络求解行为，非水锤验证 |
| 三维单相旋转 | 480 单元，600 rpm，0.002 s，U/p/壁面力/力矩/VTK 导出通过 | NCC 运动网格、真实场及后处理联通；启动时段过短，不能证明稳态泵性能 |
| 三维两相旋转 | 225 单元，600 rpm，20 μs，最大汽相率约 0.0101 | 两相源项及真实汽相率场输出；存在很强启动瞬态，不能把启动扬程当作性能曲线 |
| STEP → STL → 自动网格 → CFD | 长方体流体域 1120 单元短时运行通过 | 单体 STEP 面分类、闭合性检查、静止 CAD CFD 路径 |
| 旋转 CAD 流体域 | 环形通道，1680 单元，0.0002 s，通过 NCC、运动网格和场/载荷导出 | 完整 360° CAD 旋转区域路径；不是有蜗壳离心泵的经验验证 |
| 一维 MOC 独立基准 | 快关阀压力升高符合 Joukowsky，波到达时间检查通过 | 无摩阻、单相、弹性直管参考解 |
| 自带三维声学有限体积 | 20 m、0.1 m、480 单元、0.008 s；参考 Δp=1,275,795.115 Pa，计算 Δp≈1,275,727.709 Pa，差异约 −0.00528% | 小马赫数单相直管首次压力波；不能外推为复杂三维湍流/汽蚀准确性 |

| 实测比较 | 原始时轴插值、误差统计及不外推检查通过 | 比较工具正确；使用的是明确标注的测试数据，没有真实设备实测验证 |
| Apple Silicon 独立应用 | 冻结后离屏自检通过，含 EPANET、VTK、Gmsh STEP、本机数据库和新 GUI | 打包依赖可用；不是所有设备驱动/OS 版本人工验收 |

补充延长计算至 0.6 s：四个压力工况的后半窗平均 H 分别为 1.9243/1.9262/1.9256/0.8278 m。高压三工况半窗漂移均小于 1%，最低压力工况仍约 59.8%，因此延长后的图谱依然被拒绝激活。它揭示了低压工况的非定常性与统计不充分，不能用一个未经收敛的均值当作已标定扬程。详细可审计数值见 [verification.json](verification.json)。

原 0.3 s 扬程扫描得到的约 0.081 m NPSH3 只是该粗网格、短统计窗、周期扇区及当前物性参数下的数值交点。因稳定性门槛未通过，不能用于真实泵选型或安全余量判断。

三维声学基准另已执行 3 层网格和 3 层时间步：峰值压力/力的细层相邻变化均小于 0.0001%，但波前归一化 RMSE 随网格细化仍有约 16.2% 的相邻变化，未满足 2% 网格独立性门槛；时间步对应变化约 0.009%，通过该门槛。说明压力平台准确并不表示波前已充分解析。

网格质量使用 `checkMesh -allTopology -meshQuality` 和 Foundation 14 官方 meshQualityDict 门槛；记录全部日志。复杂 snappy 网格的凹单元需结合非正交、偏斜、体积、determinant 和实际收敛检查，不能只凭“Mesh OK”宣称网格独立。三层网格/时间步研究功能已实现，但尚未对完整真实设备完成收敛认证。

真实设备校准、独立试验集验证、完整蜗壳脉动力验证、四象限反转、微气泡坍塌与侵蚀、固体结构应力及疲劳均未完成，原因是当前没有对应设备几何与同步试验数据。软件不会自动将用户声明的数据来源标记为独立认证，也不会把未收敛结果当作成功的物理解。

复算：`python -m pytest -q`、`python gui.py --self-check build/check.json`；安装本机镜像后 `python scripts/cfd_smoke.py`。更大尺度、更多转数、细化网格与实验对比需要按 PHYSICS.md 中的程序进一步完成。
