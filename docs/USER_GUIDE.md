# 操作说明

## 设计二维与三维管网

在工具栏选择放置节点、水源或水箱，在画布单击。选择管道、离心泵或阀门连接工具，依次点击起点与终点。选择/移动模式中可以拖动节点；中键平移，滚轮缩放；三维视图左键拖动旋转。

右侧编辑参数后点击“应用参数”。水源填写总水头；需水节点填写高程与期望流量。修改类型后应用，界面会显示对应参数。泵曲线字段为 `flow_m3h`、`head_m`、`shaft_kw`、`npsh3_m`。

“分割所选管段”在三维中心线中点添加零需求节点，保留总长度与局部阻力，并复制启停事件。可从新节点增设支路。绘图位置与实际管长独立，拖动不会偷偷修改管长。

Z 与水力高程分别保存，“将 Z 映射为水力高程”可批量确认。直接连接水源或水箱的阀门需要中间连接节点。

## CAD 导入

选择“导入 CAD / DXF”，选择管道中心线图层。确认比例：米=1、毫米=0.001、厘米=0.01、英尺=0.3048。未声明单位时必须自行确认。连接和曲线容差单位均为米。

支持 LINE、二维/三维 POLYLINE、LWPOLYLINE、ARC、SPLINE、ELLIPSE 以及图块展开。不支持 DWG 原生解析；请先另存为 DXF。不会将文字、尺寸标注、外部参照或三维实体自动视作管道。

按三维端点距离连接，异高程交叉不会误接。中心线内部交叉若实际连通，应在 CAD 中打断成端点或在编辑器中明确接入节点。导入报告保留比例、图层、容差和跳过的实体。

导入草稿还需补充水源、需水量、管径与泵/阀门参数。示例 DXF 使用毫米单位和 `PIPE_CENTERLINE` 图层。

## 仿真、队列与回放

先校验管网，设置时长和步长。控制事件必须对齐报告时刻。例如：

```json
[{"hour":0.5,"target":"P1","kind":"speed","value":0.8}]
```

`enabled` 使用 0/1；`speed` 为转速比；`opening` 为阀门开度。将任务加入队列后查看执行阶段。暂停只阻止后续任务启动，取消在当前原生求解返回后生效。本机应用关闭会请求结束当前执行，排队任务与暂停状态会保存。

结果保存自己的工程快照。拖动时间轴联动图、趋势和压力/流量；点击结果中的泵查看 Q–H 曲线。当前草稿修改不会改写已完成结果。可以比较历史运行；需求、供水或期末储水不同，不给出节能率。

## 观测与校准

明确选择压力节点、流量连接及待校准泵，导入：

```csv
timestamp,pressure_m,flow_m3h,power_kw
2026-11-03T06:00:00+08:00,17.0,10.5,1.29
2026-11-03T06:05:00+08:00,17.0,10.5,1.29
```

压力为表压水头 m，流量为所选连接有符号 m³/h，功率为全部泵电输入 kW。时间必须带时区且严格递增，首条记录映射到 t=0。校准至少 10 行，需压力与流量或功率，且全部精确匹配报告时刻。存在控制事件时拒绝单参数校准。

打开 `examples/editable_network.json`，使用 `custom_network_observations.csv`，压力节点 J3、流量和待校准泵 P1、来源选择合成，可演示 0.90 曲线倍率恢复。同一求解器的合成恢复不等于实机准确度。

校准不自动覆盖工程，需主动应用为新草稿并重新计算。

## 数据和日志

数据位于系统用户应用目录，可以用 `--data-dir` 指定工作目录。同一目录仅允许一个 GUI 实例，避免重复调度。工程和完整结果都可以通过 JSON 在电脑之间移动。
