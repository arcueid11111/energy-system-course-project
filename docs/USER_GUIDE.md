# 操作说明

## 界面总览

窗口顶部是菜单栏（文件 / 编辑 / 视图 / 仿真 / 帮助）与常用工具栏；“运行仿真”（⌘/Ctrl+R）会先校验再加入本机队列。工具栏右侧显示工程名、规模和“未保存”标记。六个页签依次为：管网设计、结果与诊断、任务队列、工程与数据、观测对照与校准、三维物理与瞬变。底部日志区可拖动分隔条调整高度。

可以把工程 JSON、结果 JSON 或 DXF 文件直接拖进窗口打开；“文件 → 最近打开”保留最近 8 个工程。窗口大小与位置在下次启动时恢复。

## 设计二维与三维管网

设计页左侧是可搜索的**元素列表**（按水源、水箱、节点、泵、阀门、管道分组，点击即选中），中间是画布，右侧是参数面板。

画布上方的分段按钮选择工具，也可以用单键快捷键：V 选择、J 节点、R 水源、T 水箱、L 管道、P 水泵、K 阀门；Esc 取消正在进行的连接并回到选择。连接工具会从起点节点拉出一条预览虚线，再点击终点即可。

- 二维视图：拖动节点移动；拖动空白处、右键或中键平移；⌘/Ctrl+滚轮或触控板双指捏合以光标为中心缩放；F 或 ⌘/Ctrl+0 适应视图。
- 三维视图：左键拖动旋转，可点击选择元素。
- “网格吸附 1 m”打开后，放置和拖动节点会对齐到 1 m 网格；背景网格会随缩放显示 1/5/10/50… m 刻度。
- 鼠标悬停在元素上会显示参数摘要（结果页还会显示当前时刻的压力、流量、流速等）。

参数面板中，管径与粗糙度以 **mm** 显示（文件中仍以 m 保存）。修改后字段会变色并提示“有未应用的修改”，按回车或点击“应用参数”生效，“还原”放弃修改；切换类型会立即应用。面板还会显示连接关系、管道端点直线距离和截面流量换算、泵的最高效率点。

泵曲线用表格编辑（Q、H、轴功率、NPSH3），可增删点，下方实时绘出 H–Q 与效率曲线，并即时提示“流量须递增、扬程须递减”等错误。

“校验管网”会把问题元素在画布和元素列表中用红色 ! 标出，详细原因写入日志。

“分割所选管段”在三维中心线中点添加零需求节点，保留总长度与局部阻力，并复制启停事件。可从新节点增设支路。绘图位置与实际管长独立，拖动不会偷偷修改管长。

Z 与水力高程分别保存，“将 Z 映射为水力高程”可批量确认。直接连接水源或水箱的阀门需要中间连接节点。

## CAD 导入

选择“导入 CAD / DXF”，选择管道中心线图层。确认比例：米=1、毫米=0.001、厘米=0.01、英尺=0.3048。未声明单位时必须自行确认。连接和曲线容差单位均为米。

支持 LINE、二维/三维 POLYLINE、LWPOLYLINE、ARC、SPLINE、ELLIPSE 以及图块展开。不支持 DWG 原生解析；请先另存为 DXF。不会将文字、尺寸标注、外部参照或三维实体自动视作管道。

按三维端点距离连接，异高程交叉不会误接。中心线内部交叉若实际连通，应在 CAD 中打断成端点或在编辑器中明确接入节点。导入报告保留比例、图层、容差和跳过的实体。

导入草稿还需补充水源、需水量、管径与泵/阀门参数。示例 DXF 使用毫米单位和 `PIPE_CENTERLINE` 图层。

## 仿真、队列与回放

先校验管网，设置时长和步长。控制事件必须对齐报告时刻。例如：

```json
[{"hour":0.5,"target":"P1","kind":"speed","value":0.8}]
```

`enabled` 使用 0/1；`speed` 为转速比；`opening` 为阀门开度。将任务加入队列后，在“任务队列”查看状态、进度条、执行阶段、本地提交时间与用时；双击已完成任务直接打开结果。暂停只阻止后续任务启动，取消在当前原生求解返回后生效。本机应用关闭会请求结束当前执行，排队任务与暂停状态会保存。

### 结果与诊断

结果页顶部是指标卡：期间能耗、电费、实际供水、未满足需水、单位供水能耗（kWh/m³）、泵组综合效率（水力功 ÷ 电输入）、最低末端压力和诊断汇总。

**参数可视化**（“显示”下拉框）：

| 模式 | 节点 | 管道 |
|---|---|---|
| 节点压力 + 管道流速（默认） | 按压力着色并标注数值 | 按流速着色、线宽随流速增大 |
| 压力（节点与沿管渐变） | 按压力着色 | 颜色在两端节点压力之间渐变 |
| 管道流速 / 管道流量 | — | 按流速 / 流量着色 |
| 单位水头损失 | — | 按 m/km 着色，便于找出瓶颈管段 |

右上角图例给出色标范围，压力图例标出“所需压力”刻度。色标范围按整个模拟期间统一，回放时颜色可直接比较。勾选“水流动画”后，白色粒子沿流向移动，移动越快表示流速越大；箭头表示流向。

拖动时间轴或点击“播放”（0.5×–4×）回放模拟过程；图、右侧数值表、趋势图同步。下方趋势图可选：电功率、实际供水、未满足需求、最低末端压力（带要求线）、所选泵 Q–H 曲线（含效率曲线和当前工作点）、**所选元素时序**（节点压力或管道流量）、**沿程水力剖面**。沿程水力剖面沿管长最短路径从最近的水源画到所选节点：棕色为地面高程，绿色为测压管水头线（HGL），蓝色区域为压力，红色虚线为“高程 + 所需压力”；泵处 HGL 跃升，未选择节点时默认显示当前压力最低的需水节点。

右侧“所选元素”表列出当前时刻的压力、水头、供水、流量、流速、水头损失、泵转速 / 扬程 / 功率 / 效率及相关诊断。“运行诊断”列出越限项，点击一行会跳到首次出现的时刻并选中该元素。诊断规则（经验阈值，可在 `backend/diagnostics.py` 调整）：

- 负压（严重）、需水节点压力低于所需压力（警告）、供水不足（严重）；
- 管道流速 > 2.5 m/s（警告）、< 0.1 m/s（提示）；
- 泵流量不在最高效率点的 60–120%、关死点运行（警告）；
- 轴功率超过电机额定（严重）；
- NPSHa < NPSH3（严重）或 NPSHa < max(1.3·NPSH3, NPSH3+0.5 m)（警告）。NPSHa 取大气压头 + 吸入节点表压头 − 汽化压头，不计速度头（偏保守），NPSH3 按相似律随转速平方缩放；
- 水箱触及最低液位（警告）。

“导出 ▾”可导出完整结果 JSON、时间序列 CSV、诊断报告 CSV，以及结果图 / 趋势图 PNG。

结果保存自己的工程快照，当前草稿修改不会改写已完成结果。可以比较历史运行；需求、供水或期末储水不同，不给出节能率。

## 观测与校准

明确选择压力节点、流量连接及待校准泵，导入：

```csv
timestamp,pressure_m,flow_m3h,power_kw
2026-11-03T06:00:00+08:00,17.0,10.5,1.29
2026-11-03T06:05:00+08:00,17.0,10.5,1.29
```

压力为表压水头 m，流量为所选连接有符号 m³/h，功率为全部泵电输入 kW。时间必须带时区且严格递增，首条记录映射到 t=0。校准至少 10 行，需压力与流量或功率，且全部精确匹配报告时刻。存在控制事件时拒绝单参数校准。

打开 `examples/editable_network.json`，使用 `custom_network_observations.csv`，压力节点 J3、流量和待校准泵 P1、来源选择合成，可演示 0.90 曲线倍率恢复。同一求解器的合成恢复不等于实机准确度。

校准不自动覆盖工程，需主动应用为新草稿并重新计算。

## 数据和日志

数据位于系统用户应用目录，可以用 `--data-dir` 指定工作目录。同一目录仅允许一个 GUI 实例，避免重复调度。工程和完整结果都可以通过 JSON 在电脑之间移动。
