FLOWSTATE v2.1.0：管网设计、运行诊断与三维结果可视化更新。

- 节点压力与管道流速同屏着色，增加流量、单位水头损失、沿管压力渐变、统一色标、水流粒子和悬停数值。
- 增加水源至所选节点的沿程水力剖面、所选元素时序、单位供水能耗和泵组综合效率。
- 增加低压、缺水、流速、泵工况、电机过载、NPSH 裕量和水箱液位诊断，点击告警定位元素与时刻，支持 CSV 报告导出。
- 增加可搜索元素列表、网格吸附、光标中心缩放与触控板捏合、毫米管径编辑、泵曲线表格与预览、菜单、最近文件、拖放打开和图片导出。
- 修复小窗口及长参数面板的滚动访问，增加成果聚焦；三维 CFD 结果使用真实场的着色表面、切片及汽相等值面。
- 诊断失败时显示“诊断未完成”；沿程剖面排除已关闭连接；水箱告警保留最低液位。

Windows x64、Apple Silicon macOS、Linux x64 分别构建；Intel Mac 不构建。下载应用包后无需安装 Python。三维 OpenFOAM 求解需安装本机 OpenFOAM Foundation 14，或导入对应架构离线 Docker 镜像。普通管网与已有场文件查看无需 OpenFOAM。

所有求解和数据存储都在使用者电脑完成。诊断阈值属于经验规则，结果用于所建模型；设备结论需结合实测数据。已有弹性水锤、两相汽蚀、耦合和数值校核模块继续保留，具体状态见 docs/PHYSICS.md、docs/VERIFICATION.md、docs/CFD_INSTALL.md。
