# OpenFOAM reference case inputs

The `openfoam14/impeller` and `openfoam14/throttle` dictionaries originate from
the OpenFOAM Foundation's OpenFOAM-14 tutorials, commit
`31554318f4674a8538e6e05bb899332151ef138f`.

Source: https://github.com/OpenFOAM/OpenFOAM-14/tree/31554318f4674a8538e6e05bb899332151ef138f/tutorials

Original OpenFOAM notices are preserved. OpenFOAM is GPL-3.0; its license is
included alongside these inputs. FLOWSTATE generates modified run directories
from these inputs and records all modifications and hashes in the case manifest.
These are numerical benchmark geometries, not measured equipment CAD. No
upstream Allrun shell scripts are executed by the application.
